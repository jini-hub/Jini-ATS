# Jini-ATS

### 스마트 인사·채용 관리 시스템

**Jini-ATS**는 채용공고 등록부터 지원자 관리, ATS 적합도 분석, 채용 현황 및 리포트까지 하나의 화면에서 관리할 수 있도록 개발 중인 HR 채용관리 시스템입니다.

HR 담당자가 반복적으로 수행하는 채용공고 관리, 지원자 관리, 채용 단계 관리 및 지원자 검토 업무를 하나의 서비스에서 효율적으로 처리할 수 있도록 만드는 것을 목표로 합니다.

# 📊 ATS 분석

Jini-ATS는 채용공고의 요구사항과 지원자의 경력 및 역량을 비교하여 ATS 적합도를 분석합니다.

### ATS 분석 항목

* Job Description
* 핵심 키워드
* 지원자 보유 역량
* 경력 적합도
* 경력 연차
* 기술 및 역량
* 학력
* 종합 ATS 점수

### ATS 점수

ATS 점수는 지원자 검토를 위한 참고 지표로 사용됩니다.

```text
85점 이상   강력추천
70~84점     검토추천
50~69점     검토
50점 미만   보류
```

> ATS 점수는 채용 담당자의 최종 판단을 대신하지 않습니다.
> 실제 채용 여부는 채용 담당자가 지원자의 경력, 역량, 면접 결과 및 조직의 채용 기준 등을 종합적으로 검토하여 결정해야 합니다.

# 💾 데이터 관리

현재 Jini-ATS는 **브라우저 및 앱의 Local Storage를 기반으로 데이터를 저장**합니다.

따라서 현재 데이터는 서버 DB에 저장되는 방식이 아니라 사용하는 기기 내부에 저장됩니다.

### 데이터 흐름

```text
사용자 입력
    ↓
Jini-ATS State
    ↓
Local Storage
    ↓
브라우저 / 앱에 데이터 저장
```

### 주의사항

Local Storage 기반 구조이므로 다음과 같은 경우 데이터가 유지되지 않을 수 있습니다.

* 브라우저 데이터 삭제
* 앱 데이터 삭제
* 기기 초기화
* 다른 기기에서 앱 실행

중요한 데이터는 **백업 기능을 이용하여 별도로 보관하는 것을 권장합니다.**

# 📱 Android APK

Jini-ATS는 Android 환경에서 사용할 수 있도록 APK 형태로 빌드할 수 있습니다.

프로젝트의 `www/index.html`을 기반으로 Android APK를 생성하며 GitHub Actions를 이용한 자동 빌드 환경을 구성하고 있습니다.

```text
Jini-ATS
    ↓
www/index.html
    ↓
Android Build
    ↓
APK
```

APK는 Android 기기에 직접 설치하여 사용할 수 있습니다.

# 🏗️ 프로젝트 구조

Jini-ATS는 별도의 복잡한 프론트엔드 프레임워크에 의존하지 않고 현재 프로젝트 구조를 최대한 단순하게 유지합니다.

```text
Jini-ATS
├── docs/
│   └── index.html
│
├── www/
│   └── index.html
│
├── README.md
│
└── .github/
    └── workflows/
        └── build.yml
```

### `docs/index.html`

PC 및 모바일 브라우저에서 테스트하고 배포하기 위한 웹 버전입니다.

### `www/index.html`

Android APK 빌드에 사용되는 애플리케이션 파일입니다.

### `README.md`

프로젝트 설명, 기능 및 버전 정보를 관리합니다.

### GitHub Actions

Android APK 자동 빌드를 담당합니다.
