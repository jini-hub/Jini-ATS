# Jini-ATS

### 스마트 인사채용 관리 시스템

**Jini-ATS**는 채용공고 등록부터 지원자 관리, AI 기반 이력서 분석, ATS 적합도 분석 및 채용 리포트까지 하나의 화면에서 관리할 수 있도록 만든 HR 채용관리 시스템입니다.

기존 HR 업무에서 반복적으로 발생하는 이력서 검토와 지원자 관리 업무를 줄이고, 채용 담당자가 보다 빠르게 지원자를 비교·검토할 수 있도록 하는 것을 목표로 합니다.

---

## 🚀 Jini-ATS 2.0

현재 버전은 **Jini-ATS 2.0**입니다.

2.0에서는 기존의 ATS 기능과 데이터 구조를 최대한 유지하면서, 전체적인 사용자 인터페이스(UI)와 사용자 경험(UX)을 새롭게 개선합니다.

기존의 기능 중심 관리자 화면에서 벗어나 **iOS 스타일의 깔끔하고 직관적인 HR 관리 화면**을 지향합니다.

### 2.0 디자인 방향

* Apple/iOS 스타일의 깔끔한 UI
* Pretendard 기반의 가독성 높은 글꼴
* 밝은 `#F2F2F7` 배경
* 흰색 기반의 Rounded Card UI
* 부드러운 그림자와 테두리
* Blue / Indigo 계열의 포인트 컬러
* 모바일과 PC를 함께 고려한 반응형 디자인
* 직관적인 아이콘과 Badge UI
* 지원자 및 ATS 점수를 한눈에 확인할 수 있는 화면 구성
* 모바일 환경에서 앱처럼 사용할 수 있는 Navigation

# 📊 ATS 분석

채용공고(Job Description)와 지원자의 경력 및 역량을 비교하여 적합도를 분석합니다.

### ATS 분석 요소

* JD 핵심 키워드
* 지원자 보유 키워드
* 경력 적합도
* 경력 연차
* 보유 기술
* 학력
* 종합 ATS 점수

### ATS 결과

지원자별 분석 결과를 다음과 같이 구분합니다.

| ATS 점수 | 추천 상태 |
| -----: | ----- |
| 85점 이상 | 강력추천  |
| 70~84점 | 검토추천  |
| 50~69점 | 검토    |
| 50점 미만 | 보류    |

※ ATS 점수는 채용 담당자의 최종 판단을 대신하기 위한 것이 아니라 지원자 검토를 돕기 위한 참고 자료입니다.

# 🤖 AI 기술

Jini-ATS는 Google Gemini API를 활용하여 채용 업무를 지원합니다.

AI는 다음과 같은 작업에 활용됩니다.

* PDF 이력서 분석
* 지원자 정보 추출
* 경력 요약
* 주요 경력 정리
* 지원자 핵심 요약
* JD 키워드 분석
* 지원자와 채용공고의 적합도 분석

AI가 생성한 결과는 참고용이며, 최종적인 채용 판단은 사용자가 직접 수행합니다.

---

# 💾 데이터 관리

Jini-ATS는 지원자 및 채용공고 데이터를 브라우저/앱의 로컬 저장 영역을 기반으로 관리합니다.

따라서 중요한 데이터를 안전하게 보관하기 위해 데이터 백업 및 복원 기능을 제공합니다.

### 권장 사용 방법

1. 지원자 및 채용공고 데이터를 등록합니다.
2. 필요한 경우 ATS 분석을 진행합니다.
3. 중요한 데이터는 정기적으로 백업합니다.
4. 기기 변경 또는 데이터 복구가 필요한 경우 백업 파일을 이용하여 복원합니다.
